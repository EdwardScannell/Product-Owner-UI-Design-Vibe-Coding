## How they're built

- Each site is one self-contained `index.html` file: HTML, CSS, and JavaScript with no framework and no build step.
- To run one locally, download its folder and open `index.html` in a browser.
- Forms and leaderboards save to the browser's local storage. Nothing is sent anywhere.

Businesses, people, clients, prices, and reviews on these pages are illustrative.
