Product Owner · UI Design · Vibe Coding

Ed Scannell
front-end concepts

Five working websites, each built from a product brief I wrote. I set the audience, the look and feel, and exactly how every piece should move, then built it with Claude and kept reviewing and redirecting until it met the brief. Each site is a single self-contained HTML file with no framework and no build step.

  1. 01 · BriefAudience, mood, palette, and the must-have behaviors, written down before any code.
  2. 02 · BuildDirected Claude through the build, one self-contained page per concept.
  3. 03 · ReviewTested in the browser, named what missed the brief, and iterated until it held.

01

Brass by Bezalel

E-commerce storefront · handmade brass jewelry

A high-end shop for a four-artisan brass workshop, with an archaic, otherworldly feel. The logo plaque doubles as the page's only light source, so every highlight and shadow on the site falls the same way.

  • 3D tumbling brass ring in the hero, cycling the season's four pieces in lilac halos
  • Glass display-case carousel: hover dissolves the glass and the piece glows brighter
  • Drag-to-rotate 360° viewer on every piece page, with the artisan's first-person notes
  • Hour-by-hour booking grid for an appointment at the maker's bench
  • CSS 3D transforms
  • Inline SVG
  • Hash routing
  • Vanilla JS

02

Decco Design Co.

Designer portfolio + lead capture · Art Deco

A one-page portfolio for a fictional Cambridge graphic designer, built around the question every visiting client asks: have you done work like mine?

  • Search plus four filter rows (style, industry, organization type, deliverable) across 12 projects
  • Every tag on a project card is a one-click shortcut into the filters
  • "Let's Connect" form modeled on an Airtable prospects table, with inline validation
  • Light and dark themes, plus a thumb-reach bottom nav on mobile
  • Faceted search
  • Form validation
  • Airtable data model
  • Light / dark

03

Taqueria La Mexicana

Restaurant landing page · concept

A "fiesta-luxe" landing page for a counter-service taqueria: fast tacos, slow margaritas. Built as a concept, so prices, reviews, and contact details are samples.

  • Open or closed status worked out live from the posted hours
  • Swaying papel picado banner and a scrolling specials ticker
  • Taco picker that swaps the description and price; heat ratings for five house salsas
  • Reviews carousel, ordering, directions, catering, and events, plus an optional music toggle
  • SVG illustration
  • Web Audio
  • Reduced-motion support
  • Vanilla JS

04

Frog Pondian Design Co.

Mobile-first portfolio · Deco nocturne

A second take on the designer portfolio, this time for a designer who works out of a bookstore. Mobile-first, in an evergreen and antique-brass palette.

  • A "matching desk": free-text search plus multi-select chips for style, industry, organization, and format
  • Nine portfolio pieces, each drawn as original vector art
  • Contact form that files leads to a studio ledger, ready to sync to Airtable
  • Portfolio and Connect buttons pinned within thumb reach
  • Mobile-first
  • Multi-select filtering
  • SVG
  • localStorage

05

Edward's Arcade

Playable retro arcade · three original games

A neon 1984 arcade floor with three playable cabinets and a back wall of attract-mode demos.

  • Apex Rush: a pseudo-3D racer with checkpoints, AI rivals, and an extend clock
  • Wizard's Crypt, a dungeon crawl across three crypts, and The Attack, an alien-siege shooter
  • Top-10 leaderboards with arcade-style initials entry, saved in the browser
  • Every sound effect synthesized in code, with no audio files
  • Canvas 2D
  • Game loops
  • Web Audio
  • localStorage
